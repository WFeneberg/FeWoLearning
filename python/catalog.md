## Beginner (001–035) — fundamentals
Numbers & strings, f-strings, lists/tuples/sets/dicts, comprehensions, slicing,
`for`/`while`/`enumerate`/`zip`, functions & default args, `*args`/`**kwargs`,
exceptions, file I/O, `pathlib`, `datetime`, `collections.Counter`, sorting with
`key`, `math`/`random`.

## Intermediate (036–070) — idioms & stdlib
Generators & `yield`, decorators, context managers, `dataclasses`, `enum`,
`typing` (generics, `Protocol`), `itertools`, `functools` (`reduce`/`partial`/
`cache`), regular expressions, `json`/`csv`, `argparse`, `namedtuple`/`TypedDict`,
custom exceptions, `defaultdict`, comprehension pipelines.

## Advanced (071–090) — concurrency, performance, internals
`asyncio` tasks & gathering, `threading` vs `multiprocessing`, `concurrent.futures`,
descriptors, metaclasses, `__slots__`, custom iterators/`__iter__`, `contextvars`,
memoization structures, `heapq`/priority queues, `functools.singledispatch`,
profiling (`timeit`/`cProfile`), `weakref`, generator-based pipelines.

## Expert (091–100) — architecture & systems
A mini web framework (WSGI), a small ORM/query builder, a plugin system via entry
points, an async task queue, a DSL/interpreter, a type-checked event bus, a
streaming parser, a caching layer with TTL + LRU, a dependency-injection container,
a property-based test suite (Hypothesis-style).
