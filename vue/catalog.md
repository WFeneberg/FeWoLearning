## Beginner (001–035) — reactivity & templates
`ref`/`reactive`/`computed`, `watch`/`watchEffect`, composables, template syntax,
`v-if`/`v-for`/`v-bind`/`v-on`, `v-model` on inputs, class/style binding, props
(typed), emits, simple lifecycle (`onMounted`).

## Intermediate (036–070) — component patterns
Slots (named/scoped), `provide`/`inject`, `defineModel`, custom `v-model`, dynamic
components, `<Teleport>`, `<Suspense>`, async components, form validation, list
transitions, composable extraction, `toRefs`/`toRef`, template refs.

## Advanced (071–090) — state, routing, performance
Pinia stores (state/getters/actions), Vue Router (guards, lazy routes), render
functions & JSX, custom directives, `<KeepAlive>`, virtualized lists, debounced
inputs, error boundaries (`onErrorCaptured`), plugin authoring, testing with
`@vue/test-utils` (events, async updates).

## Expert (091–100) — architecture
A typed store module pattern, a composable-based data-fetching layer with caching,
an SSR-safe component, a headless component library, a design-system token layer,
a form engine driven by schema, an undo/redo history composable, a WebSocket-backed
live store, a micro-frontend mount, an accessibility-audited widget.
